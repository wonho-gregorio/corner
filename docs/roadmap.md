# 로드맵

현재 저장소는 애플리케이션 골격과 모듈 경계를 마련한 단계입니다. 아래 순서는 기능 간 선행 관계를 고려한 권장안이며 확정 일정은 아닙니다.

## 1. 개발 기반 완성

- 최초 Flyway 마이그레이션과 테스트용 데이터베이스 전략 결정
- 공통 API 응답 및 오류 형식 결정
- 프론트엔드 라우팅, HTTP 클라이언트와 화면 구조 구성
- 로컬 CORS와 개발 프록시 설정

## 2. 회원과 인증

- 회원·보호자·가족관계 데이터 모델과 CRUD
- 관리자 계정, 로그인과 역할별 권한
- 개인정보 접근 및 변경 감사 정책

## 3. 수강권과 출석

- 기간제·횟수제·혼합형 회원권 발급, 휴회, 만료와 차감 규칙
- 자유·수업 출석, 선택적 퇴실 처리와 중복 출석 방지
- 회원 상태와 수강권에 따른 출석 가능 여부 검증

## 4. 수업과 결제

- 수업·시간표·정원 관리
- 출석 시 수업 선택과 공휴일·임시 휴강 처리
- 청구, 일시불·분할 납부, 부분 납부, 미납과 환불 이력

## 5. 알림과 운영 준비

- SOLAPI 문자·알림톡 연동, 자동 발송 규칙과 발송 이력
- 실패 재시도 및 중복 발송 방지
- 관리자 대시보드, 통계와 Excel 내보내기
- 백업·모니터링·배포 절차
- 보안 점검과 주요 사용자 흐름의 통합 테스트

## 추후 확장

- QR 회원증과 온라인 전용 무인 출석
- PG·카드 단말기·계좌 결제 데이터 연동
- 가족 묶음 결제와 자동 가족 할인
- 다지점 관리와 회원용 앱

## 기능 완료 기준

- 업무 규칙과 예외가 테스트로 검증됨
- 모듈 경계 검증이 통과함
- 필요한 DB 마이그레이션이 포함됨
- API와 데이터 문서가 갱신됨
- 권한, 개인정보와 실패 처리 방식이 검토됨
- 프론트엔드 lint와 build가 통과함
