# 제품 요구사항

## 문서 목적

이 문서는 도장 회원 관리 프로그램의 1차 MVP 범위와 지금까지 합의한 운영 정책을 정리합니다. 아직 구현되지 않은 기획 기준이며, 정책이 변경되면 구현과 함께 이 문서를 갱신합니다.

## 제품 범위

- 단일 도장을 위한 관리자용 클라우드 웹 프로그램으로 시작합니다.
- 주요 사용자는 관리자와 직원입니다.
- 회원용 로그인과 앱은 1차 범위에서 제외합니다.
- 여러 지점, 실제 결제 승인, 가족 묶음 결제와 QR 회원증은 추후 확장합니다.
- 데이터 구조는 외부 결제 연동과 다지점 확장을 고려하되 초기 화면에는 관련 기능을 노출하지 않습니다.

## 사용자와 권한

### 관리자

- 모든 회원·회원권·결제·출석·수업·알림·통계와 설정 관리
- 결제 수정, 환불과 할인 승인
- 미납 또는 미결제로 제한된 출석의 예외 승인
- 직원 계정과 권한 관리

### 직원

- 허용된 범위에서 회원 등록·수정과 일반 출석 처리
- 관리자 전용 설정, 환불, 중요 결제 수정과 출석 제한 해제 불가

중요 변경과 예외 승인에는 처리자, 처리 시각, 변경 전후 값과 사유를 기록합니다.

### 직원 계정 관리

- 직원의 자체 회원가입은 제공하지 않고 관리자가 직원 계정을 생성합니다.
- 직원 목록에서 기존 계정을 선택하거나 `직원 추가`로 새 계정을 등록합니다.
- 기본 정보는 직원 이름, 로그인 아이디, 역할과 계정 상태로 구성합니다. 로그인 아이디는 직원이 로그인할 때 입력하는 고유한 아이디입니다.
- 계정 상태 선택값을 활성화·비활성화의 유일한 제어로 사용하며 별도의 비활성화 버튼을 중복 제공하지 않습니다.
- 직원 역할에는 `회원 관리`, `출석 처리`, `정상 결제 등록` 권한을 각각 켜거나 끌 수 있습니다. 관리자 역할은 전체 권한이 고정됩니다.
- 통계, 할인 행사·상품·문자 설정, 환불·결제 취소, 중요 정정과 관리자 예외 승인은 직원에게 부여할 수 없습니다.
- 새 직원은 임시 비밀번호로 시작하고 첫 로그인 시 본인 비밀번호로 변경합니다. 관리자는 현재 비밀번호를 조회하지 않고 임시 비밀번호만 다시 발급할 수 있습니다.
- 계정을 비활성화하면 진행 중인 로그인 세션을 만료시키고 이후 로그인을 차단합니다.
- 마지막 활성 관리자 계정은 비활성화하거나 직원으로 변경할 수 없습니다.
- 계정 생성·활성화·비활성화, 비밀번호 재발급과 권한 변경은 변경 이력에 기록합니다.
- 등록·수정 작업 버튼은 별도 최상단 작업줄 없이 입력 영역 하단에 한 번만 표시합니다.

## 회원 관리

### 회원 정보

필수 정보는 이름, 휴대전화 번호, 등록일과 회원 상태입니다. 선택 정보는 프로필 사진, 생년월일, 성별, 주소, 비상 연락처, 건강상 주의사항과 관리자 메모입니다.

- 회원번호는 자동 발급합니다. 예시는 `202609-0001`이며 형식은 추후 설정 가능하게 합니다.
- 회원 상태는 활동, 휴회와 퇴회로 관리합니다.
- 정보 등록·수정 담당자와 시각을 기록합니다.
- 문자, 카카오 알림톡과 개인정보 수집·이용 동의를 기록합니다.
- 회원 상태와 개별 회원권 상태는 서로 분리합니다.

### 보호자와 가족관계

- 보호자 이름, 연락처와 회원과의 관계를 저장합니다.
- 회원 간 부모, 자녀, 형제·자매, 배우자와 기타 관계를 연결할 수 있습니다.
- 연결된 가족은 회원 상세 화면에서 확인하고 이동할 수 있습니다.
- 가족 연결 해제는 회원·회원권·결제 이력을 삭제하지 않습니다.
- 가족 묶음 결제, 대표 납부자와 자동 가족 할인은 추후 범위입니다.

## 회원권

### 회원권 유형

| 유형 | 관리 기준 |
| --- | --- |
| 기간제 | 시작일, 종료일과 이용 상태 |
| 횟수제 | 전체 횟수, 잔여 횟수와 유효기간 |
| 기간·횟수 혼합형 | 종료일과 잔여 횟수를 모두 적용 |

회원권 상태는 이용 예정, 이용 중, 일시 정지, 만료, 횟수 소진과 해지로 관리합니다. 한 회원이 여러 회원권을 동시에 보유할 수 있습니다.

### 상품 결제 정책

회원권 상품에는 정상 판매가와 함께 다음 정책을 설정합니다.

- 부분·분할 납부 허용 여부
- 기본 납부 방식: 일시불, 분할 또는 발급 시 선택
- 최대 분할 횟수
- 최소 최초 납부 금액 또는 비율
- 완납 전 이용 허용 여부
- 미납 시 출석 허용, 경고 또는 제한 정책

상품의 기본 정책은 회원권 발급 시 관리자 권한으로 개별 변경할 수 있습니다. 상품 기본 가격과 실제 회원에게 적용한 할인·최종 계약 금액은 분리합니다.

### 회원권 상품 등록 화면

- 상품 유형은 기간권, 횟수권과 기간·횟수 혼합형으로 구분합니다.
- 기간권은 이용 기간만 입력합니다.
- 횟수권은 전체 이용 횟수와 유효기간을 입력합니다.
- 혼합형은 이용 기간과 전체 이용 횟수를 모두 입력합니다.
- 기간과 유효기간은 개월 또는 일 단위로 설정하고, 회원권 발급 시 시작일을 기준으로 종료일을 계산합니다.
- 정상 판매가와 신규 판매 가능 여부를 설정합니다. 판매를 중지해도 기존 회원권과 과거 이력은 유지합니다.
- 부분·분할 납부와 휴회 허용의 기본값은 모두 `허용 안 함`입니다.
- 부분·분할 납부를 허용한 경우에만 최대 분할 횟수, 최소 최초 납부 기준과 완납 전 이용 허용 여부를 표시하고 설정합니다.
- 부분·분할 납부를 다시 끄면 완납 전 이용 허용도 함께 해제하고 화면에서 숨깁니다.
- 휴회를 허용한 경우에만 최대 횟수, 1회·전체 최대 기간과 최소 이용 기간을 표시하고 설정합니다.
- 발급된 회원권에는 당시 상품 유형, 이용 조건, 가격, 결제·출석과 휴회 정책을 스냅샷으로 보존합니다. 이후 상품 수정은 새로 발급하는 회원권에만 적용합니다.

### 할인 행사 등록 화면

- 행사명, 시작일·종료일, 할인 방식과 할인값, 적용 회원권 상품, 활성 여부와 관리자 메모를 하나의 연속된 양식에서 입력합니다.
- 할인 방식은 정률 또는 정액 중 하나를 선택합니다.
- 한 행사에 여러 회원권 상품을 선택할 수 있지만 회원권 발급 시에는 행사 하나만 적용합니다.
- 회원 유형별 대상 조건은 두지 않습니다.
- 오른쪽 요약에서 행사 기간, 할인 조건, 선택 상품 수와 상품별 예상 판매금액을 실시간으로 확인합니다.
- 행사명과 기간, 0보다 큰 할인값 및 적용 상품 한 개 이상을 필수로 검증합니다.
- 정률 할인은 100%를 초과할 수 없고 정액 할인은 선택한 각 상품의 정상가격보다 작아야 합니다.
- 등록·수정 화면 최상단에는 별도의 취소·저장 작업줄을 두지 않고 양식의 요약 또는 하단에 버튼을 한 번만 표시합니다.

### 휴회

상품별로 휴회 허용 여부, 최대 횟수, 1회 및 전체 최대 기간, 최소 이용 기간과 만료일 자동 연장 여부를 설정합니다.

- 휴회 중 해당 회원권의 사용과 출석을 중지합니다.
- 예정 종료일에 자동 재개하며 관리자가 조기 재개할 수 있습니다.
- 실제 휴회 기간만큼 만료일을 자동 연장합니다.
- 횟수제와 혼합형은 잔여 횟수를 유지합니다.
- 상품 정책을 초과하는 휴회는 관리자가 사유를 남기고 예외 승인할 수 있습니다.
- 여러 회원권을 보유한 경우 선택한 회원권만 휴회하는 것이 기본입니다.

### 출석 시 회원권 선택

1. 선택한 수업에서만 사용할 수 있는 전용 회원권을 우선합니다.
2. 그다음 만료일이 가장 가까운 사용 가능 회원권을 선택합니다.
3. 직원은 출석 확정 전에 다른 사용 가능 회원권으로 변경할 수 있습니다.
4. 실제로 선택되고 차감된 회원권을 출석 이력에 저장합니다.

## 결제

### 청구와 결제 분리

납부해야 할 금액인 청구와 실제로 받은 돈인 결제 내역을 분리합니다.

- 청구: 청구 금액, 납부 예정일, 납부액, 잔액과 상태
- 결제: 실제 결제 금액, 일시, 수단, 처리자와 메모
- 청구 상태: 예정, 부분 납부, 완납, 미납과 취소
- 결제 수단: 현금, 카드와 계좌이체를 기본 제공
- 일시불과 여러 차수의 분할 납부를 모두 지원
- 실제 결제 합계가 청구 금액에 도달하면 완납으로 처리

1차에서는 관리자가 결제를 기록합니다. 추후 연동을 위해 입력 출처, 결제 제공사, 외부 거래번호, 승인번호, 동기화 상태와 원거래 식별자를 저장할 수 있게 설계합니다.

### 결제 등록 진입 흐름

- 신규 회원은 `회원정보 → 회원권 등록 → 결제 등록`의 3단계로 처리합니다.
- 기존 회원의 재등록과 추가 회원권은 `회원 상세 → 회원권 등록 → 결제 등록`으로 처리합니다.
- 부분납부·분할납부와 미납의 후속 결제는 `회원 상세 → 결제 탭 → 미납 청구` 또는 `결제 관리 → 납부 예정·미납`에서 대상 청구를 선택해 등록합니다.
- 결제 등록은 항상 회원과 청구가 정해진 상태에서 시작하며 연결되지 않은 독립 결제는 만들지 않습니다.

### 결제 취소·정정·환불 화면

- 결제 내역 또는 회원 상세의 결제 탭에서 원거래를 선택해 진입합니다.
- 결제 취소, 결제 정정과 전체·부분 환불을 한 화면에서 구분해 처리합니다.
- 결제 취소는 선택한 원거래 전액에 대한 취소 거래를 새로 만들고 청구 상태와 잔액을 다시 계산합니다.
- 결제 정정은 원거래 취소와 올바른 결제 거래 생성을 한 작업으로 처리합니다.
- 환불은 원거래 금액 안에서 관리자가 환불금액, 공제액, 수단, 사용 기간·횟수와 사유를 입력합니다.
- 환불과 회원권 해지는 선택적으로 한 작업에 연결할 수 있으며, 환불만 처리하면 회원권 상태를 유지합니다.
- 해지를 함께 처리할 때 해지 적용일과 이용 중지 시점을 선택합니다. 기본값은 처리일 해지와 저장 완료 즉시 이용 중지입니다.
- 이용 중지 시점은 저장 완료 즉시, 해지 적용일 시작 시각 또는 해지 적용일 종료 시각 중에서 선택할 수 있습니다.
- 원거래는 수정하거나 삭제하지 않고 취소·정정·환불 거래와 감사 이력을 연결해 보존합니다.
- 모든 작업은 관리자 전용이며 처리 사유를 필수로 입력합니다.

### 결제 상태에 따른 출석

- 기본 정책은 미납 또는 부분 납부 상태에서도 출석 허용입니다.
- 상품 또는 개별 회원권에 경고, 납부일 경과 시 제한, 완납 전 제한을 설정할 수 있습니다.
- 제한된 출석은 관리자만 사유를 입력하고 예외 승인할 수 있습니다.
- 예외 승인에는 회원권, 제한 사유, 미납 금액, 승인자, 시각, 사유와 차감 내역을 기록합니다.

### 해지와 환불

- 전체 환불과 부분 환불을 지원합니다.
- 1차에서는 시스템이 환불액을 자동 결정하지 않고 관리자가 계산해 입력합니다.
- 해지일, 환불액, 환불 수단, 사유, 사용 기간·횟수, 공제액과 처리자를 기록합니다.
- 환불은 원래 결제 내역과 연결합니다.
- 해지된 회원권은 즉시 사용을 중지합니다.

## 출석과 수업

### 출석 방식

- 자유 출석과 시간표에 연결된 수업 출석을 모두 지원합니다.
- 1차에서는 직원이 이름, 전화번호 또는 회원번호로 검색해 출석을 처리합니다.
- 기간제는 유효 기간을 확인하고, 횟수제와 혼합형은 출석 시 1회를 차감합니다.
- 출석 취소 시 해당 출석으로 차감한 횟수를 자동 복원합니다.
- 중복 출석 방지 기준은 업무 화면 기획 시 최종 확정합니다.

### 출석 등록과 취소·정정 화면

- 신규 출석은 `출석 처리` 화면에서 회원을 검색한 뒤 일반 출석 또는 PT 출석으로 등록합니다.
- 이미 등록된 출석의 취소와 시간 정정은 `출석 이력`에서 대상 기록을 선택해 별도 상세 화면에서 처리합니다.
- 취소·정정 화면에는 원본 출석 시각, 회원, 수업, 사용 회원권, 차감 결과와 처리자를 먼저 표시합니다.
- 출석 취소와 입실·퇴실 시간 정정을 구분합니다.
- PT 출석 취소 시 해당 출석에서 차감한 1회를 같은 작업에서 자동 복원합니다. 취소 화면에서 횟수 복원만 따로 실행할 수는 없습니다.
- PT 횟수 수동 조정은 출석 취소·정정과 분리된 관리자 전용 작업으로 처리합니다.
- 취소 또는 정정 사유는 필수이며 원기록을 변경하거나 삭제하지 않고 연결된 이력을 새로 생성합니다.
- 직원은 본인이 등록한 당일 출석만 취소할 수 있습니다. 다른 처리자의 기록, 과거 기록, PT 복원과 시간 정정은 관리자만 처리합니다.
- 등록·수정 화면 최상단에는 별도의 취소·저장 작업줄을 두지 않고 처리 요약 또는 하단에 작업 버튼을 한 번만 표시합니다.

### PT 횟수 수동 조정 화면

- 회원 상세의 `회원권` 탭에서 조정할 PT 횟수권 또는 혼합형 회원권을 선택해 진입합니다.
- 회원, 회원번호, 상품, 유효기간, 발급 횟수, 사용·차감 횟수와 현재 잔여 횟수를 먼저 표시합니다.
- 관리자는 `횟수 추가` 또는 `횟수 차감`을 선택하고 조정 횟수와 필수 사유를 입력합니다.
- 잔여 횟수를 직접 덮어쓰지 않고 양수 또는 음수의 수동 조정 이력을 새로 생성한 뒤 잔여 횟수를 다시 계산합니다.
- 차감 후 잔여 횟수는 0회 미만이 될 수 없습니다.
- 기존 발급·출석 차감·복원·조정 이력을 보존하고 최근 횟수 이력을 한 흐름에서 보여줍니다.
- 횟수 수동 조정은 회원권 유효기간을 변경하지 않습니다. 기간 변경은 회원권 상세의 별도 작업으로 처리합니다.
- 저장 전 요약에서 조정 전·후 잔여 횟수, 조정 값, 대상 회원권과 처리자를 확인합니다.
- 이 기능은 출석 취소·정정과 분리된 관리자 전용 기능이며 작업 버튼은 입력 영역 하단에 한 번만 표시합니다.

### 퇴실

- 퇴실 시간은 관리할 수 있지만 필수는 아닙니다.
- 기본 설정은 선택 입력이며 출석 시간만 있어도 정상 출석으로 인정합니다.
- 퇴실 기록이 있으면 체류 시간을 계산합니다.
- 직원은 누락된 퇴실 시간을 나중에 추가하거나 수정할 수 있습니다.

### 수업

- 반복 시간표와 날짜별 실제 수업을 구분합니다.
- 반복 수업에는 수업명, 일반·PT 구분, 요일, 시작·종료 시각, 담당 지도자와 운영 상태를 관리합니다.
- 수업·시간표 메인 화면은 `주간 시간표`와 `수업 목록` 보기로 구성합니다.
- 주간 시간표에서 수업을 선택하면 반복 일정, 시간, 담당 지도자, 운영 상태와 이번 주 출석 요약을 오른쪽에 표시합니다.
- 반복 수업 수정과 날짜별 출석 처리는 구분합니다. 실제 참석자는 날짜별 수업에서 출석 처리 화면으로 이동해 등록하고 출석 기록에서 확인합니다.
- 사전 예약, 대기자, 정원 제한, 공휴일 자동 반영과 임시 휴강 처리는 1차 범위에서 제외합니다.
- 회원은 출석 처리 시 참여할 수업을 선택합니다.
- 자유 출석과 수업 출석은 출석 기록에서 구분합니다.

### 수업 등록 화면

- `수업 추가`에서는 매주 반복되는 수업의 정보와 시간표를 하나의 연속된 양식으로 등록합니다.
- 수업 구분은 일반 수업과 개인 PT 중 하나를 선택합니다.
- 공통 기본 정보는 수업명, 담당 지도자, 운영 상태와 시간표 표시 색상입니다.
- 반복 요일을 한 개 이상 선택하고 시작·종료 시각, 운영 시작일과 선택적인 운영 종료일을 입력합니다. 종료 시각은 시작 시각보다 늦어야 합니다.
- 일반 수업은 출석 처리에서 찾기 쉽도록 대상 회원 그룹을 하나 이상 선택합니다.
- 개인 PT는 특정 회원 한 명과 해당 회원의 유효한 PT 회원권을 확인해 연결합니다.
- 이 화면에서 사전 예약, 대기자와 정원을 관리하지 않으며 실제 참석은 날짜별 출석 처리에서 등록합니다.
- 오른쪽 요약에서 수업 구분, 수업명, 담당 지도자, 반복 요일·시간과 참여 대상을 확인합니다.
- 별도의 최상단 취소·저장 작업줄 없이 요약 하단에 작업 버튼을 한 번만 표시합니다.

### 추후 출석 인증

QR 회원증 발급과 무인 출석은 1차 범위에서 제외합니다. 추후 별도 로그인 경로를 가진 온라인 전용 무인 출석 화면으로 구현합니다. 관리자 메뉴나 결제 정보에는 접근할 수 없는 제한된 기기 권한을 사용하며 오프라인 출석은 지원하지 않습니다.

## 알림

### 대상과 채널

- 관리자 내부 알림과 회원 대상 자동 발송을 모두 지원합니다.
- 외부 발송은 SOLAPI를 1차 공급자로 사용합니다.
- 성인은 본인, 미성년자는 보호자를 기본 수신자로 사용합니다.
- 회원별로 본인, 보호자 또는 둘 다를 선택할 수 있습니다.
- 결제 알림과 수업 알림의 수신자를 각각 설정할 수 있습니다.
- 문자와 카카오 알림톡의 수신 동의를 별도로 기록합니다.

### 자동 발송 기본값

- 기간권의 재등록일 당일에 문자메시지 한 건만 자동 발송합니다.
- 재등록일은 현재 기간권 종료일의 다음 날로 계산합니다.
- 재등록일 전에 새 기간권을 등록했다면 예정 문자를 발송하지 않습니다.
- 같은 회원에게 같은 재등록일 문자를 중복 발송하지 않습니다.
- 결제 예정·미납, 만료 사전 안내와 PT 잔여 횟수 안내는 관리자 화면에는 표시하되 MVP 자동 문자 대상에서는 제외합니다.

재등록 문자의 사용 여부, 당일 발송 시각과 메시지 내용을 관리자가 변경할 수 있습니다. 회원권을 미리 연장하면 불필요한 예정 알림을 취소합니다. 야간 발송 제한, 중복 방지, 실패 재시도, 수동 재발송과 발송 이력을 지원합니다.

### 재등록 문자 설정 페이지

- 알림 관리 메뉴에 관리자 전용 `재등록 문자 설정` 페이지를 제공합니다.
- 자동 발송 사용 여부, 재등록일 당일 발송 시각과 SOLAPI에 등록된 발신번호를 설정합니다.
- 발송 직전에 회원권 연장 여부와 문자 수신 동의를 다시 확인합니다.
- 문자 제목과 본문을 수정하고 예시 회원 정보가 적용된 실제 치환 결과를 미리 볼 수 있습니다.
- 기본 치환 항목은 `{도장명}`, `{회원명}`, `{회원권명}`, `{재등록일}`, `{도장연락처}`입니다.
- 지원하지 않는 치환 항목, 비어 있는 본문과 야간 발송 시각은 저장 전에 검증합니다.
- 현재 문구의 예상 SMS·LMS 유형과 글자 수를 화면에 안내합니다.
- 등록된 관리자 테스트 번호로만 테스트 발송할 수 있으며 실제 회원 발송과 구분하여 이력에 기록합니다.
- API 키와 시크릿은 화면에 표시하지 않습니다.
- 설정 변경에는 변경 전후 값, 관리자와 변경 시각을 기록하고 실제 발송 건에는 사용한 문구의 스냅샷을 보존합니다.
- 별도의 최상단 취소·저장 작업줄 없이 미리보기 하단에 설정 저장 버튼을 한 번만 표시합니다.

### 발송 이력·실패 재처리 화면

- 실제 회원 문자와 관리자 테스트 발송을 명확히 구분합니다.
- 오늘 발송, 성공, 실패·재처리 필요와 테스트 발송 요약 수치를 제공하며 선택하면 해당 조건으로 목록을 조회합니다.
- 회원명·수신번호, 발송 결과, 실제·테스트 구분과 기간으로 이력을 검색합니다.
- 목록에는 발송 예정·처리 시각, 회원과 마스킹된 수신자, 회원권·재등록일, 발송 구분, 결과와 실패 사유를 표시합니다.
- 기록을 선택하면 발송 시도 횟수, 공급자 오류 정보, 사용한 설정 버전과 최종 치환 문구 스냅샷을 상세 영역에 표시합니다.
- 일시적인 공급자 오류는 같은 최종 문구 스냅샷으로 관리자가 재발송할 수 있습니다.
- 유효하지 않은 연락처는 재발송하지 않고 회원정보의 연락처 수정으로 연결합니다.
- 성공한 발송과 테스트 발송에는 재발송 작업을 제공하지 않으며 원기록은 변경하지 않습니다.

### SOLAPI 연동 보안

- API 키와 시크릿은 저장소에 저장하지 않습니다.
- 운영 환경에서는 `SOLAPI_API_KEY`, `SOLAPI_API_SECRET` 환경 변수 또는 비밀 관리 서비스를 사용합니다.
- 개발 중에는 실제 발송이 없는 내부 테스트 공급자를 사용합니다.
- 실제 테스트 발송은 허용된 테스트 수신번호로 제한합니다.
- 공급자 변경에 대비해 알림 모듈과 SOLAPI 구현을 분리합니다.

## 통계

- 통계 메뉴와 조회 화면은 관리자만 접근할 수 있습니다.
- 기간과 회원 그룹을 선택해 화면에서 조회합니다.
- 신규 등록, 회원권 판매, 실제 수납액과 출석을 상단 요약 수치로 표시합니다.
- 실제 수납액은 취소·환불을 차감한 결제 처리일 기준이며 금액은 `만원` 단위로 표시합니다.
- 결제와 출석의 월별 추이, 현재 회원 상태 구성을 확인할 수 있습니다.
- 만료 예정, PT 잔여 부족, 부분납부·미납, 환불과 일반·PT 출석을 운영 상세로 표시합니다.
- 요약 수치와 운영 상세를 선택하면 동일한 기간·회원 그룹 조건이 적용된 회원, 회원권, 결제 또는 출석 목록으로 이동합니다.
- 문자 발송 성공·실패는 통계로 집계하지 않고 알림 관리의 발송 이력에서만 확인합니다.
- MVP에서는 Excel·CSV 파일 내보내기 기능을 제공하지 않습니다.

## 1차 MVP 제외 범위

- 다지점 관리
- 회원용 앱과 회원 로그인
- QR 회원증과 무인 출석
- 오프라인 출석
- PG, 카드 단말기 또는 계좌 결제 데이터 연동
- 가족 묶음 결제와 자동 가족 할인
- 환불 금액 자동 계산

## 구현 전에 남은 주요 정책

- 동일 전화번호와 재등록 회원의 중복 처리
- 할인 종류, 직원 할인 한도와 관리자 승인 기준
- 같은 날 여러 출석·수업의 횟수 차감 기준
