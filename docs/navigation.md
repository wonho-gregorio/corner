# 화면 구조와 업무 흐름

## 문서 목적

이 문서는 1차 MVP의 관리자·직원 메뉴, 주요 화면 구성과 이동 흐름을 정의합니다. 기능별 세부 업무 규칙은 [제품 요구사항](product-requirements.md)을 따릅니다. 화면 예시의 회원명, 건수, 금액과 날짜는 레이아웃 확인용이며 운영 기본값으로 확정한 값이 아닙니다.

## 관리자 메뉴

```text
대시보드

회원 관리
├── 회원 목록
└── 회원 등록

회원권 관리
├── 발급 회원권
├── 회원권 상품
└── 할인 행사

결제 관리
├── 결제 내역
├── 납부 예정·미납
└── 취소·환불

출석 관리
├── 출석 처리
└── 출석 이력

수업 관리
└── 수업·시간표

알림 관리
├── 재등록 문자 설정
└── 발송 이력·실패 재처리

통계

설정
├── 도장 정보
├── 회원 그룹
└── 직원 계정·권한
```

- 데스크톱 화면은 왼쪽 메뉴를 기본으로 사용하고 현재 메뉴를 강조합니다.
- 상단에는 회원 통합검색과 회원 등록으로 바로 이동하는 빠른 작업을 둡니다.
- 목록 화면은 검색·필터, 상태 표시, 결과 표와 상세 이동을 공통 구조로 사용합니다.
- 요약 수치와 주의 항목을 선택하면 해당 조건이 적용된 관리 목록으로 이동합니다.
- 회원 상태별 탭과 보관 회원 메뉴는 제공하지 않습니다. 보관 회원은 신규 등록 중 중복 후보 확인에서만 제한적으로 표시합니다.

## 직원 메뉴

직원에게는 관리자가 부여한 개별 권한에 따라 `회원 관리`, `출석 관리`, `정상 결제 등록` 메뉴만 표시합니다. 통계, 회원권 상품, 할인 행사, 환불, 문자 설정과 직원 계정 메뉴는 표시하지 않으며 서버에서도 접근을 차단합니다.

## 대시보드

대시보드는 오늘 처리할 업무를 우선해 다음 정보를 표시합니다.

- 오늘 출석 수와 최근 출석
- 활성 회원 수와 최근 신규 등록
- 7일·30일 이내 만료 예정 회원권
- 오늘·7일 이내 납부 예정과 현재 미납 건수·금액
- PT 잔여 3회 이하 회원
- 오늘 결제 합계와 최근 결제
- 재등록 문자 발송 실패와 재처리 필요 건

각 요약 항목은 회원권, 결제, 출석 또는 발송 이력의 관련 목록으로 이동합니다. 문자 발송 성공·실패는 대시보드에서 운영 주의 항목으로만 표시하고 통계 지표로 집계하지 않습니다.

## 회원 등록 흐름

```text
회원정보 입력
→ 기존·보관 회원 후보 확인
→ 신규등록 또는 기존 회원 재활성화
→ 회원 그룹 선택
→ 회원권 상품과 시작일 선택
→ 할인 행사 적용
→ 결제 등록
→ 등록 완료
```

보관 회원은 신규등록 중 일치 후보가 발견될 때만 확인할 수 있습니다. 재활성화 시 기존 `member_id`를 유지하고 연락처, 보호자 정보, 회원 그룹과 동의 상태를 다시 확인합니다.

### 회원 등록 화면

회원 등록은 상단의 `회원정보 → 회원권 → 결제` 3단계로 진행합니다.

1. 기본정보
   - 필수: 이름, 생년월일, 회원 그룹
   - 성인 필수: 회원 휴대전화 번호
   - 미성년 필수: 보호자 이름, 관계와 보호자 연락처
2. 동의
   - 개인정보 수집·이용 동의
   - 재등록 안내 문자 수신 동의
3. 선택정보
   - 주소, 비상 연락처와 건강상 주의사항
   - 기본 화면에서는 접어두고 필요할 때 펼쳐 입력

- 이름·생년월일 또는 연락처가 일치하는 보관 회원이 있으면 등록 화면 안에서만 마스킹된 후보를 안내합니다.
- 담당자는 `기존 정보 불러오기` 또는 `동명이인 신규등록`을 선택해야 다음 단계로 이동할 수 있습니다.
- 오른쪽 등록 요약에는 회원명, 그룹, 신규·재활성화 구분과 다음 단계를 표시합니다.
- `다음: 회원권 등록`은 회원정보를 검증한 뒤 회원권 단계로 이동합니다.
- `회원만 저장`은 회원권 없이 `CONSULTING` 상태로 저장합니다.
- `취소`는 저장하지 않고 회원 목록으로 돌아가며 입력 내용이 있으면 이탈 확인을 표시합니다.

## 회원 목록과 상세

회원 목록은 하나의 화면에서 다음 검색과 필터를 제공합니다.

- 이름, 전화번호와 회원번호 통합검색
- 회원 그룹, 회원 상태, 회원권 상태·상품과 결제 상태 필터
- 만료 임박, 미납과 PT 잔여 부족 상태 표시

목록에는 회원, 그룹, 회원권, 이용 상태, 종료일 또는 잔여 횟수, 결제 상태와 최근 출석을 표시합니다. 회원을 선택하면 상세 화면으로 이동합니다.

회원 상세는 `요약`, `회원권`, `결제`, `출석·PT`, `상담 기록`, `문자 기록`, `변경 이력`으로 구성합니다. 상단 빠른 작업으로 회원정보 수정, 회원권 등록, 출석 처리와 결제 등록을 제공하고, 관리자 전용 휴회·시작일 변경·예외 처리에는 권한을 명확히 표시합니다.

## 회원권 등록과 관리

### 회원권 등록 화면

- 기간권과 PT 횟수권을 구분해 선택합니다.
- 상품을 선택하면 기간·횟수, 정상가격과 상품 정책을 자동 반영합니다.
- 시작일은 직접 지정할 수 있고 종료일은 상품 단위와 시작일로 계산해 읽기 전용으로 표시합니다.
- 현재 적용 가능한 할인 행사 하나를 선택하고 할인과 최종 계약금액을 자동 계산합니다.
- 상품의 부분·분할 납부 허용 여부와 미납 출석 정책을 결제 단계 전에 안내합니다.
- 오른쪽 요약에서 회원, 상품, 이용 기간, 할인과 결제 예정금액을 계속 확인합니다.

### 회원권 관리 화면

`발급 회원권`, `회원권 상품`, `할인 행사`를 한 메뉴 안에서 구분합니다.

- 발급 회원권: 회원·상품 통합검색, 상태·그룹·유형 필터와 이용 기간·잔여 횟수·결제 상태 표시
- 회원권 상품: 유형, 기간 또는 횟수, 정상가격, 부분·분할 납부, 미납 출석과 판매 상태 관리
- 할인 행사: 행사명, 적용 상품, 기간, 정액·정률 할인, 상태와 적용 이력 확인

행사는 활성 상태, 적용 기간과 적용 상품만으로 선택 가능 여부를 판단합니다. 회원 유형별 조건은 두지 않으며 발급 당시 행사 정보와 최종 계약금액을 보존합니다.

## 결제 등록과 관리

### 결제 등록 화면

- 기본 납부 방식은 `전액 납부`이며 최종 계약금액을 결제금액으로 자동 입력합니다.
- 필요한 경우에만 부분납부, 분할납부 또는 미납을 선택합니다.
- 기본 결제수단 한 개를 표시하고 `결제수단 추가`로 카드, 현금과 계좌이체를 조합할 수 있습니다.
- 결제 항목 합계, 선택한 납부금액, 계약금액과 남은 금액을 실시간으로 표시합니다.
- 합계 불일치와 초과 결제는 저장을 차단하고 부족액 또는 초과액을 안내합니다.
- 부분납부는 잔액 납부 예정일을, 분할납부는 회차별 금액과 예정일을 입력합니다.

### 결제 관리 화면

`결제 내역`, `납부 예정·미납`, `취소·환불`로 구분합니다.

- 결제 내역은 결제 묶음과 그 안의 결제수단별 실제 거래를 함께 확인합니다.
- 납부 예정·미납은 회원, 청구, 예정일, 청구금액, 납부액, 잔액과 상태를 표시하고 결제 등록으로 이동합니다.
- 취소·정정과 환불은 관리자만 원거래를 선택하고 사유를 입력해 별도 거래로 기록합니다.
- 원거래는 수정하거나 삭제하지 않고 정정·환불 거래와 연결해 보존합니다.

회원권 해지 적용일과 이용 중지 시점은 아직 확정하지 않았으므로 취소·환불 화면의 세부 처리 흐름은 후속 정책 결정 뒤 보완합니다.

## 출석 처리와 이력

```text
이름·전화번호·회원번호 검색
→ 회원권과 미납 상태 확인
→ 일반 출석 또는 PT 수업 선택
→ 출석 확정
→ PT이면 횟수권 1회 차감
```

- 출석 처리 화면은 회원 검색 결과, 현재 사용 가능한 기간권·PT 횟수권과 미납 상태를 함께 표시합니다.
- 일반 출석은 일일 출석만 집계하고 횟수를 차감하지 않습니다.
- PT 출석은 실제 수업과 사용할 횟수권을 확인한 뒤 1회를 차감합니다.
- 제한된 출석의 관리자 예외 승인에는 제한 사유, 미납액과 승인 사유를 표시합니다.

출석 이력은 회원, 날짜, 일반·PT 유형과 정상·취소 상태로 검색합니다. 출석 시각, 회원, 수업 또는 사용 회원권, 차감·복원 결과와 처리자를 표시하고 원기록과 정정 이력을 연결해 보여줍니다.

직원은 본인이 등록한 당일 출석만 사유를 입력해 취소할 수 있습니다. 다른 처리자의 기록, 과거 기록과 PT 횟수 복원은 관리자만 처리합니다. 퇴실 시간은 선택 입력으로 추가하거나 수정할 수 있습니다.

## 수업·시간표

- 주간 반복 시간표에서 요일·시간별 수업명과 담당 지도자를 확인합니다.
- 일반 수업과 PT 수업을 구분하고 실제 수업의 참석자와 출석 기록으로 이동합니다.
- 회원의 출석 처리 화면에서 참여할 수업을 선택할 수 있습니다.
- 사전 예약, 대기자, 정원 제한, 공휴일 자동 반영과 임시 휴강 처리는 MVP에서 제외합니다.

## 재등록 문자 설정과 발송 이력

재등록 문자 설정은 관리자 전용 화면입니다.

- 자동 발송 사용 여부와 재등록일 당일 발송 시각
- 문자 제목과 본문, 지원 치환 항목과 실제 치환 결과 미리보기
- 예상 SMS·LMS 유형과 글자 수
- SOLAPI 등록 발신번호 선택과 허용된 테스트 번호로 테스트 발송
- 비어 있는 본문, 지원하지 않는 치환 항목과 야간 발송 시각 검증

발송 이력은 실제 회원 문자와 테스트 발송을 구분합니다. 발송 예정·처리 시각, 회원과 마스킹된 수신자, 회원권과 재등록일, 결과와 실패 사유를 표시합니다. 연락처 오류는 회원정보 확인으로, 일시적인 공급자 오류는 관리자 재발송으로 연결합니다. 실제 발송에는 설정 버전과 최종 치환 문구 스냅샷을 보존합니다.

## 통계

통계는 관리자만 조회합니다. 기간과 회원 그룹을 선택해 다음 항목을 확인합니다.

- 회원 상태와 신규 등록 추이
- 회원권 판매, 만료 예정과 PT 잔여 부족
- 결제 예정, 부분납부, 미납, 완납과 환불
- 일별·회원별·수업별 출석

요약 수치를 선택하면 관련 회원권, 결제 또는 출석 목록으로 이동합니다. 문자 발송 성공·실패는 통계에서 제외하며 Excel·CSV 내보내기는 제공하지 않습니다.

## 설정

### 도장 정보

- 도장명, 대표 연락처와 주소
- 회원번호 표시 형식
- 출석의 선택적 퇴실 시간 사용 여부
- 재등록 문자 설정 화면으로의 이동

### 회원 그룹

- 기본 그룹은 초등부, 중·고등부와 성인부입니다.
- 그룹명, 표시 순서와 활성 상태를 관리합니다.
- 사용 중이거나 이력이 있는 그룹은 삭제하지 않고 비활성화합니다.
- 그룹별 현재 회원 수를 표시합니다.

### 직원 계정·권한

- 관리자가 직원 계정을 생성·활성화·비활성화합니다.
- 직원별로 회원 관리, 출석 처리와 정상 결제 등록 권한을 설정합니다.
- 통계, 상품·행사, 문자 설정, 환불과 중요 정정은 관리자 전용으로 유지합니다.
- 마지막 활성 관리자 보호 규칙과 계정·권한 변경 이력을 적용합니다.

## 재등록 흐름

```text
대시보드 또는 회원 검색
→ 기존 회원 상세
→ 기간권 추가
→ 기존 종료일 다음 날부터 자동 연장
→ 할인 행사 선택
→ 결제
→ 재등록 문자 발송 대상에서 제외
```

회원정보 수정, 회원권 등록, 결제와 상담 메모 추가는 회원 상세 화면에서 바로 실행할 수 있게 합니다.
