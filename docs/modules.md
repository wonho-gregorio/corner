# 업무 모듈

현재 백엔드에는 아래 일곱 개 Spring Modulith 모듈의 경계만 선언되어 있습니다. 상세 정책과 API는 구현 과정에서 확정합니다.

| 모듈 | 책임 | 대표 기능(예정) |
| --- | --- | --- |
| `auth` | 인증과 접근 권한 | 로그인, 계정, 역할, 인가 |
| `member` | 회원과 보호자 정보 | 회원 등록·수정·조회, 보호자 연결 |
| `membership` | 이용 자격과 수강권 | 기간권·횟수권 발급, 사용, 만료 |
| `attendance` | 시설 이용 기록 | 출석, 퇴실, 출석 이력 |
| `lesson` | 수업 운영 | 수업, 시간표, 정원과 참석자 |
| `payment` | 금전 거래 | 결제, 환불, 미수금 |
| `notification` | 메시지 전달 | 알림 요청, 발송 결과와 재시도 |

## 예상 협력 관계

아래 흐름은 설계를 위한 출발점이며 구현된 계약이 아닙니다.

```text
auth ── 사용자 식별과 권한 제공
  │
member ── 회원 기본 정보 제공
  ├── membership ── 이용 가능 여부 제공
  │      ├── attendance ── 출석 시 사용 가능 여부 확인
  │      └── lesson ── 수업 출석 시 자격 확인
  ├── payment ── 회원의 거래 기록 관리
  └── notification ── 연락 대상 정보 참조 또는 알림 이벤트 수신
```

## 모듈 설계 체크리스트

각 모듈을 구현하기 전에 다음을 문서화합니다.

- 모듈이 소유하는 데이터와 변경 권한
- 외부에 공개하는 명령, 조회 또는 이벤트
- 지켜야 할 업무 불변 조건
- 실패 처리와 중복 요청 처리 방식
- 다른 모듈에 필요한 정보의 최소 범위
